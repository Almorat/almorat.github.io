# Almorat - Personal Portfolio

## About

Personal portfolio website showcasing my projects, skills, and professional journey as a software developer.

## Features

- 🎨 **Modern Design** - Clean, responsive interface with smooth animations
- 🌙 **Dark Mode Support** - Automatic theme based on system preferences
- 📱 **Mobile First** - Fully responsive design for all devices
- ⚡ **Fast Loading** - No frameworks, just vanilla HTML, CSS & JavaScript
- ♿ **Accessible** - Semantic HTML and proper ARIA labels

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/Almorat/almorat.github.io.git
```

2. Open `index.html` in your browser, or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

3. Visit `http://localhost:8000`
